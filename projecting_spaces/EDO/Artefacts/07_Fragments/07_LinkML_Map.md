# 07 - LinkML Map

## Ziel

Ein LinkML Map Beispiel für die Transformation in das interne Format.

## Beschreibung

LinkML Map wird verwendet, um die konkreten Mappings zwischen den Quellschemata (DMP, SMS) und dem Zielschema (Internes Format) zu definieren. Dies ermöglicht automatisierte Transformationen.

## Aufgaben

- [ ] LinkML Map für DMP → Internes Format erstellen
- [ ] LinkML Map für SMS → Internes Format erstellen
- [ ] Mappings testen
- [ ] Transformation validieren
- [ ] Dokumentation ergänzen

## Werkzeuge

- **LinkML Map** - Für Schema-Mapping

## Deliverables

- Zwei LinkML Map-Dateien
- Testergebnisse der Transformation
- Validierungsbericht
