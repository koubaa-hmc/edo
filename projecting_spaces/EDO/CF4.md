# Use programming interfaces of target platforms to publish and search metadata

Target platforms present typically application programming interfaces ([[API]]s):
- [[API]] behave differently, but a common kernel can be abstracted
- There is no exhaustive list of [[Target platform]]s, especially for different [[Domain]]s

EDO should:
- Implement clients as [[Plugin]]s
- During the edition of metadata, EDO should interactively search for similar [[Dataset]]s, to help [[Enrich]] and [[Differentiate]] the current [[Metadata record]] from already registered [[Dataset]]s
